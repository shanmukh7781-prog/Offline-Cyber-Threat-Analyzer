# Offline-Cyber-Threat-Analyzer
Built a standalone offline tool that replicated SIEM features without requiring internet connectivity. Designed for demo and academic use cases, the system performed log analysis, IP and domain reputation checks, HTTP header inspection, and file hash verification using simulated intelligence datasets. It provided threat mapping, correlation rules (e.g., brute force attempts, scanning patterns), anomaly detection, and risk scoring in a fully disconnected environment. Outputs included SOC-style reports and structured threat map data, making the project ideal for environments where real-time external threat feeds are unavailable.
